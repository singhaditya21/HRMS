### 27. [medium] DATA RESIDENCY IS NOT THE MOAT IT IS COMMONLY ASSUMED TO BE. The DPDP Act permits cross-border transfer by default and empowers the government only to restrict transfers to specifically notified countries — a blacklist mechanism, not a localisation mandate.

CAVEAT ADDED THIS PASS: both the MeitY PDF and the India Code PDF returned HTTP 403, so the statutory text could NOT be re-fetched. The characterisation is consistent with the statute as enacted but rests on statutory knowledge rather than a fetched primary source in this pass, and should be confirmed with counsel before being used in positioning. ## Opportunities

- Own the statutory cadence as a product promise. Both India-capable global vendors publish tax slabs two budget cycles stale — verified for Deel against the AY 2026-27 government table this pass. A published, dated, changelog-backed statutory-currency guarantee ('slabs updated within N days of the Finance Act') is a differentiator no global vendor currently offers, and it is cheap relative to building payroll.
- Copy Akai's architecture, not Deel's product.
